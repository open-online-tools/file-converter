Add proof of concept file converter: Rust/WASM + React.js web app

- Rust/WebAssembly converter engine with support for image (PNG/JPEG/BMP/GIF), markup (HTML/Markdown), and serialization (JSON/YAML/TOML/CSV) conversions
- React.js UI with mobile-first responsive design, drag-and-drop file upload, format picker, progress bar, and result download
- Web Worker integration to run WASM conversions off the main thread (non-blocking UI)
- GitHub Pages deployment via CI/CD
- Comprehensive roadmap for future file conversion categories
